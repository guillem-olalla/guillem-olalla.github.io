# guillem-olalla.github.io

Portfolio técnico de Guillem Olalla. Son fichas de arquitectura de los sistemas que he construido: un servidor MCP propio, agentes, un SaaS y un autopilot de candidaturas. Cada ficha describe cómo funciona el sistema real, no una propuesta.

## Cómo verlo

- **Publicado:** https://guillem-olalla.github.io. GitHub Pages sirve la rama `main` desde la raíz.
- **En local:** es un único `index.html`, sin build ni dependencias (solo carga las fuentes de Google Fonts). Se abre directamente en el navegador, o se sirve con `python -m http.server 8000` desde la raíz del repo y se entra en http://localhost:8000.

## Los proyectos son privados

Los repos de los sistemas que describen las fichas son privados, y el portfolio no enlaza a ninguno. Si quieres ver alguno por dentro, hago un walkthrough: [linkedin.com/in/guillem-olalla](https://linkedin.com/in/guillem-olalla).

- `index.html`: la página entera, con estilos y script en el mismo archivo.
