Política de privacidad de mailagent

mailagent es una herramienta personal. La he construido yo, Guillem Olalla, para ordenar mi propia bandeja de Gmail, y no la usa nadie más.

Última actualización: 2 de noviembre de 2026

Qué datos lee

Usa la API de Gmail solo sobre mi cuenta. Hoy tiene el permiso gmail.metadata, que da acceso a las cabeceras y las etiquetas de los correos, nunca al cuerpo ni a los adjuntos. De cada correo lee el remitente, el asunto, la fecha en que llegó y sus etiquetas.

Más adelante usará gmail.modify, para poner etiquetas y archivar. Google permite con ese permiso más cosas, como enviar correo o mandarlo a la papelera. mailagent no las hace, y un test de su código falla si el flujo intenta llamar a cualquiera de esas funciones.

Qué hace con ellos

Un servicio en un servidor mío decide la etiqueta de cada correo con reglas fijas, a partir del remitente y el asunto. Hoy no envía nada a ningún modelo de IA ni a ningún servicio externo. Si eso cambia, esta página cambiará antes.

Dónde se guardan

Cada decisión queda en un registro en ese servidor, al que solo accedo yo: el id del correo, lo que se ha leído de él, la etiqueta elegida y si se archiva. Se borra a los 30 días. El permiso de Google se guarda cifrado en el mismo servidor.

Con quién se comparten

Con nadie. No se venden ni se usan para publicidad, y solo salen del servidor hacia la propia API de Google.

El uso de los datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
